# 手机浅色模式全面审核

日期：2026-09-25

## 原因与修改

手机页面使用的共享 premium 样式固定为深色背景、白色图标文字；切换主题后部分 Tailwind 按钮背景变浅，子元素仍是白字，底部导航及弹窗也没有对应浅色样式。

- 新增仅由手机入口加载的 `mobile/mobile-theme.css`，定义主题颜色变量，为底部导航、弹窗、标题、按钮、标签、音量滑杆、选中及锁定状态提供浅色配色。
- 画面页未选按钮使用白底深字，选中状态使用深红底白字。按钮图标与文字跟随按钮颜色，消除白底白字。
- 已选卡片移除固定深色内联背景及冗余卡片变量，使用播放中／下一首语义类；歌名和播放指示条改用主题变量。首次打开默认高亮“已选”。
- 互动首页、搜索、表单、记录背景和文字适配浅色；图片上的文字、宣传图和视频预览保留适合素材背景的对比度。空记录提示取消浅色模式下的过低透明度。
- 修正即时切换后太阳／月亮图标与重新打开面板时不一致的问题，并为主题按钮增加可访问名称。
- HTML 及相关模块版本更新，当前主题样式为 `20260925-light2`。未修改 API、缓存机制、房间状态或播放命令。
