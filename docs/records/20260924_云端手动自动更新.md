# 云端手动／自动更新（2026-09-24）

## 需求和实现

- 删除包列表内重复的未授权提示，保留标题下方的红色授权／到期提示。
- 更新目录下新增“下载更新：手动更新／自动更新”，选择后点“保存设置”。默认手动，配置持久化为 cloud.update_mode。
- 自动模式由点歌服务器后台调度：启动检查，30 秒读取配置和授权，每次尝试至少间隔 5 分钟，关闭页面仍可运行。需保持服务器程序运行及有效云端更新授权。
- 自动、手动共用包更新锁、签名授权、10GB 空间保护、最大磁盘回退、SHA256 和实际播放入库验证。完整安装包跳过；失败按 5 分钟间隔重试。
- 保存设置与调度启动共用锁，调度取得锁后重读当前模式，避免切换手动后旧检查仍启动。更新进行中暂时禁止修改目录及模式。
- 调度 future 由 HTTP 服务生命周期持有，停止或重启后端时取消，避免旧实例重复调度。
- GET/PUT /api/v1/cloud/config 对应 getCloudConfig/saveCloudConfig，字段 downloadDir/updateMode；status 同步返回 updateMode，严格拒绝未知模式。API 文档已更新。
