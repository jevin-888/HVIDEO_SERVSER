# 文件夹同目录加密修复（2026-09-21）

## 问题

视频加密工具的单个文件模式允许源文件和输出文件夹位于同一目录，但文件夹模式此前把“源目录=输出目录”判定为目录树冲突，因此选择歌曲目录作为输出目录时直接失败。

## 修改

- `scripts/encrypt_videos.py`：允许文件夹模式输入目录和输出目录完全相同。批量扫描只识别常规视频后缀，生成的 `.hvideo` 不会再次被扫描。
- 继续拒绝输入目录与输出目录互为父子目录，避免输出子目录中的普通视频被意外纳入同一批任务。
- 继续预先拒绝重复目标和已有 `.hvideo`，工具不会覆盖已有文件，原视频始终保留。
- `scripts/video_encryption_ui.py`：在界面提示和错误说明中明确同目录规则。
- 同步更新 `docs/20260915_固定密钥视频加密.md` 的使用规则。

## 验证

- `python -B -m unittest discover -s tests -p test_video_encryption.py`：12 项通过。
- `python -B -m unittest discover -s tests -p test_video_encryption_ui.py`：8 项通过，包含桌面文件夹模式输入/输出同目录。
- 临时目录批量实测：输入目录和输出目录相同，生成 `sample.hvideo`，原 `sample.mp4` 保留，命令返回成功。
- 已重新编译独立 EXE：`D:\HVIDEO\Hvideo_server\视频加密工具.exe`。
