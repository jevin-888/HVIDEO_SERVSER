# 视频加密工具隐藏解密（2026.09.26.1）

## 使用方式

1. 打开 `D:\HVIDEO\Hvideo_server\视频加密工具-2026.09.26.1.exe`。
2. 点击窗口内容区左上角“视频加密”标题 10 次，显示“解密视频”按钮。点击计数仅在本次运行中有效，重新打开默认隐藏。
3. 点击“解密视频”切换到解密界面，选择“单个视频”或“整个文件夹（含子目录）”。
4. 选择 `.hvideo` 文件或其所在文件夹、输出文件夹，点击“开始解密”。使用“切换加密”可回到原加密界面。

## 修改

- `scripts/encrypt_videos.py`：新增与 `encrypt(source, output, ffmpeg, ffprobe, profile, control)` 参数一一对应的 `decrypt()`；沿用 v1 固定密钥配置，以流复制方式将 CENC 音视频还原为普通 MKV，将 `hvideo_ass_v1` 元数据中的 ASS 歌词恢复成字幕轨，不重新编码。
- 加密与解密共用 `plan()` 扫描和 `publish()` 原子发布逻辑；解密只扫描 `.hvideo`，保留子目录结构，支持与输入同目录输出。原文件始终保留，已有目标跳过，处理期间新出现的同名目标也禁止覆盖。
- 输出前无密钥探测轨道并完整解码检查音视频，校验失败不发布文件；对已有可恢复解码错误的文件也采用严格校验。取消或异常会删除本次未完成的 `.partial` 和临时 ASS 文件。
- `scripts/video_encryption_ui.py`：十次标题点击解锁、解密模式切换、单个/文件夹模式、文件筛选、进度及统计中文提示。运行任务时禁止切换，复用现有停止和错误处理流程；批量遇到错误停止，已经完成和跳过的文件保留。
- `视频加密工具.vbs`：优先启动本次带版本号的新 EXE，找不到时兼容原 EXE。构建时原 `视频加密工具.exe` 正在运行，因此保留原进程和旧文件，交付新版独立文件。
- 新增解密回归测试，扩展现有 DPI 布局测试检查隐藏按钮解锁后不与其他按钮重叠；无服务器、PAD、播放器 API 或加密协议变更。
