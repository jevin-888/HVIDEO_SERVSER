## 修复

此前云端连接检测只检查 health，导入按钮依赖业务库 songs.cloudFileId，无法发现云端已发布的 VOD 更新包。

页面改名“云端更新”。登录进入程序立即自动检查，之后每 30 秒刷新，在页面左上角显示连接状态、最近检查时间；移除右上角手动检查及输入歌曲 ID 的旧入口。断网显示原因，不循环弹窗；请求未完成时不重叠发起。自动检查只读，下载由“下载并更新曲库”启动。

云端配置增加“选择目录”，桌面管理端调用 Windows 原生文件夹窗口，选择运行点歌服务器电脑的目录。媒体根目录、歌曲扫描支持多选；空闲歌曲、歌星图片和云端下载使用单选。取消选择保留旧值，中文目录可正常返回。浏览器远程访问不再显示自制目录浏览弹窗，提示使用服务器电脑上的桌面管理端或直接填写路径。

更新包显示歌曲资料数和可下载视频数。所有文件先校验大小与 SHA256，再导入资料和登记播放索引；拒绝目录穿越、重复文件名、Windows 保留名、不同来源下载 URL。每个清单版本独立保存，已有可播放文件不覆盖。全局更新互斥，失败可重试，校验通过的已有文件复用。重启中断的任务会进入失败状态，后续更新继续按发布版本顺序处理。

使用现有 XLSX 导入器与增量路径匹配服务。仅支持标准 XLSX 曲库，其他源格式明确提示，避免错误解析。新业务 API 与页面调用一对一；旧通用歌曲下载 API 保留供已有客户端使用，页面已移除旧歌曲 ID 导入代码。

## 接口

- GET /api/v1/cloud/config、PUT /api/v1/cloud/config：沿用配置接口，仅管理员，密钥不返回。
- GET /api/v1/cloud/status：沿用连接字段，新增 packages、updateError、updating。packages 每项为 id/name/versionCode/songCount/videoCount/totalSize/installed；连接与读取包失败分别表示。
- 目录选择已在同日后续修改中改为 Windows 原生 select_directories 命令，移除 cloud/directories 接口。
- POST /api/v1/cloud/updates：仅管理员，无请求体，按版本顺序创建/复用未完成的包任务，返回 SyncTask 数组。
- GET /api/v1/cloud/tasks：沿用分页与任务进度，targetType=vodPackage 为更新包。
- POST /api/v1/cloud/download/:id：包任务重试时按当前已发布目录顺序重新调度；通用下载维持原流程。
- 云端 GET /api/vod-updates/catalog：公开已发布包与文件校验清单，详见授权服务器同日记录。
