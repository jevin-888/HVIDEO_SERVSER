# 2026-10-01 Linux 分支推送

- 分支：`linux`
- 仓库：`https://github.com/jevin-888/HVIDEO_SERVSER`
- Linux 构建入口：`npm run linux:build`。
- Linux Tauri 目标：AppImage 和 deb。
- Linux 运行目录：`$XDG_DATA_HOME/HVideo Admin`，回退到 `~/.local/share/HVideo Admin`。
- Linux 后端支持非 Windows 网卡枚举、机器标识和 `ip -o -4 addr` 定向广播解析。
- 当前 Windows 主机已通过服务器后端和 Tauri 管理端 `cargo check --offline`；Linux 原生安装包需在 Linux 主机安装 GTK/WebKitGTK 开发依赖后构建。
