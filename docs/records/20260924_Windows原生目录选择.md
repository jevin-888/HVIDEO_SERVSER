# 2026-09-24 Windows 原生目录选择

用户反馈自制目录浏览窗口难用。本次统一改为 Tauri 1.x 的 Windows 系统文件夹窗口：云端下载目录、媒体根目录、歌曲路径扫描、空闲歌曲目录、歌星图片目录全部走 `select_directories` 命令。

`DirectoryPurpose` 只允许 `cloudDownload`、`idleSongs`、`mediaRoots`、`songScan`、`singerImages` 五种用途；媒体根目录和歌曲扫描开启多选，其他用途单选。选择结果校验为绝对路径，分号路径拒绝，取消返回空值；原生窗口使用初始路径的现有父目录作为打开位置。应用级互斥锁避免重复弹出窗口。

浏览器模式没有 Windows 原生窗口能力：点击目录按钮提示“请在服务器电脑的 HVideo Admin 程序中选择文件夹”，输入框仍可输入服务器路径。上传 XLSX、APK 等 `<input type=file>` 继续使用浏览器/系统文件选择器。

删除了管理端自制目录弹窗、远程目录浏览 API、盘符卡片和相关前端 API。旧的通用云端歌曲下载 API 不受影响。
