# 云端删除立即生效，无需客户端确认（2026-09-29）

## 行为

按用户要求，云端删除操作立即删除对应更新记录，返回 deleted=true，不等待客户端在线或确认。云端按钮改为“删除”，移除“待客户服务器确认删除”和待同步数量。客户端没有删除入口，只读取云端状态并自动清理已被云端删除的本地历史与歌曲明细。视频、曲库和 sync_tasks 保留。

新版客户端每 15 秒按本地历史 ID 分批查询云端，每批最多 100 条。仅收到明确的云端删除结果才清理本地；断网、HTTP 错误、异常响应和从未上报的新记录不视为已删除，保留并继续正常上报。无需删除回执、确认队列或人工操作。

云端继续保存最小删除标记，禁止旧上报或恢复备份让已删除记录重新出现。旧版本客户端的读取/自动回执协议保留兼容，但它不决定云端删除是否生效，页面不再显示回执状态。旧协议通过 deleteIds 发起删除已禁止，仅云端后台管理员能删除。

## API 一对一

- DELETE /api/admin/server-update-records/{machine}/{id}：管理员删除，成功返回 id/deleted；等待及运行中记录仍返回 409。
- POST /api/server-update-records/sync-deletions：签名确定服务器身份，新版请求 {recordIds:[UUID]}，返回 {recordIds:[UUID],deletedIds:[UUID]}。不发送 ackIds/deleteIds。未知字段、超量、无效 UUID 拒绝，查询限定本机身份。
- 旧版兼容请求 {deleteIds:[],ackIds:[UUID]}，返回原格式；非空 deleteIds 返回 403，不能从客户端删除云端记录。
- 云端与本地记录列表不再返回 pendingDeletes。
- 客户端迁移 043_cloud_history_authority 移除旧 update_history_deletions 确认/待办表；历史、歌曲明细与下载任务不受影响。
