# 2026-10-01 Linux 版本支持

## 修改内容

- 后端保留并验证 Linux 条件编译路径，增加 Linux `ip -o -4 addr` 网卡前缀解析，用于计算播放器和收银端 UDP 定向广播地址。
- Tauri 运行目录按平台选择：Linux 使用 `$XDG_DATA_HOME/HVideo Admin`，未设置时使用 `~/.local/share/HVideo Admin`；Windows 继续使用 `%APPDATA%`。
- Linux 不再查找或复制 `yt-dlp.exe`，使用系统 PATH 中的 `yt-dlp`。
- 新增 `src-tauri/tauri.linux.conf.json`，输出 AppImage 和 deb，资源使用 Linux watchdog 二进制。
- 新增 `scripts/build_watchdog.sh` 和 `scripts/build-linux.sh`，新增 `npm run linux:build`。
- Linux 打包时临时生成配置，将 `server.host` 设为首次启动选择标记 `0.0.0.0`，将 Windows `E:/` 媒体根目录替换为 `./storage/media`；打包结束自动清理临时目录。

## 构建

```bash
npm run linux:build
```

构建产物位于 `src-tauri/target/release/bundle/`。Linux 主机需预装 Rust、Node.js、GTK/WebKitGTK 开发包、`iproute2`、`ffmpeg`、`ffprobe` 和 `yt-dlp`。

## 验证

- Windows 主机 `cargo check --offline` 通过。
- Linux 目标交叉检查已进入依赖编译；当前 Windows 环境缺少 `x86_64-linux-gnu-gcc`，因此未完成链接。WSL Ubuntu 已通过两个新增 shell 脚本的语法检查。
