## 修复

保留校验完成后再替换的逻辑。首次重命名返回 Windows 错误 5 时读取目标文件属性：

- 普通视频存在只读属性：只解除该目标文件的只读属性后重试重命名，不改变 ACL、不修改整个目录权限。
- 重试失败：恢复旧文件只读属性，保留旧视频和完整缓存，并上报占用/权限提示。
- 普通视频非只读：提示检查目标文件及目录的删除/修改权限或文件占用，同时记录 Windows 属性，避免笼统重复“拒绝访问”。
- 目录和重解析点：不解除属性，不作为普通视频操作。

属性解除、替换及失败恢复在同一个阻塞工作闭包中完成，避免异步取消发生在解除属性与恢复之间。没有先删除或截断旧视频；仍然只在新文件通过完整 SHA256 校验和歌曲资料匹配后执行。

业务 API、数据库结构、云端、调度间隔和容量保护均未更改。没有删除现场任务、历史记录或缓存。
