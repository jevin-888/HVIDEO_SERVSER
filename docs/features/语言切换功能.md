# 语言切换功能说明

## 功能概述

系统实现了双语显示功能，支持中文和印尼语：
- 中文：固定显示，不可隐藏
- 印尼语：可通过语言切换按钮控制显示/隐藏

## 实现方式

### 1. HTML结构

所有需要双语显示的地方使用以下结构：

```html
<span>中文文本</span>
<span class="indonesian-translation">印尼语文本</span>
```

### 2. CSS控制

在 `static/vod_song/client/assets/css/style-client.css` 中：

```css
/* 默认隐藏印尼语翻译 */
.indonesian-translation {
  display: none;
}

/* 当启用印尼语时显示印尼语翻译 */
body.show-indonesian .indonesian-translation {
  display: inline;
}
```

### 3. JavaScript逻辑

在 `static/vod_song/client/index.js` 中的 `initLanguageToggle()` 函数：

- 从 localStorage 读取用户选择（默认不显示印尼语）
- 根据选择添加/移除 `body` 的 `show-indonesian` 类
- 更新语言切换按钮的文本显示
- 保存用户选择到 localStorage
- 触发 `languageToggled` 自定义事件

### 4. 语言切换按钮

位置：右上角（服务按钮旁边）

```html
<button id="languageToggle" class="control-btn ...">
  <i class="fas fa-globe text-5xl mr-4"></i>
  <span id="language" class="text-3xl">中文</span>
</button>
```

按钮文本：
- 显示"中文"：表示当前仅显示中文
- 显示"印尼语"：表示当前显示中文+印尼语

## 使用的页面

所有使用 `indonesian-translation` 类的页面都支持语言切换：

1. 首页（主页按钮、已选按钮）
2. 智能控制面板（SmartlUI）
   - 标签页标题（灯光、空调、音频）
   - 音量控制
   - 温度控制
   - 灯光模式按钮
   - 空调模式按钮
   - 音效按钮
3. 底部导航栏（BottomNavUI）
4. 已选页面（SelectedUI）
5. 点歌页面（SongTopUI）
   - 筛选按钮
6. 派对页面（PartyUI）

## 用户体验

1. 默认状态：仅显示中文
2. 点击语言切换按钮：显示中文+印尼语
3. 再次点击：恢复仅显示中文
4. 用户选择会保存到 localStorage，刷新页面后保持

## 技术细节

### 状态管理

- 状态存储：`localStorage.getItem('showIndonesian')`
- 状态值：`'true'` 或 `'false'`（字符串）
- 默认值：`false`（不显示印尼语）

### CSS类控制

- 控制类：`show-indonesian`
- 作用域：`body` 元素
- 影响范围：所有 `.indonesian-translation` 元素

### 事件通知

当语言切换时，会触发自定义事件：

```javascript
window.dispatchEvent(new CustomEvent('languageToggled', { 
  detail: { showIndonesian: isShowing } 
}));
```

其他组件可以监听此事件来响应语言切换：

```javascript
window.addEventListener('languageToggled', (event) => {
  const { showIndonesian } = event.detail;
  // 处理语言切换
});
```

## 扩展性

如果需要添加更多语言：

1. 在HTML中添加对应的翻译span，使用不同的类名（如 `vietnamese-translation`）
2. 在CSS中添加对应的显示/隐藏规则
3. 在JavaScript中扩展 `initLanguageToggle()` 函数，支持多语言切换

## 注意事项

1. 中文始终显示，不受语言切换影响
2. 印尼语翻译使用 `indonesian-translation` 类标记
3. 所有新增的双语内容都应遵循相同的HTML结构
4. CSS规则使用 `display: none/inline` 而不是 `visibility`，以避免占用空间
