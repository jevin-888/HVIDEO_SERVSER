# 2026-09-21 歌曲对照与删除重复统一格式优先级

## 需求与实现

- 同编号文件统一按 HVIDEO（加密）→ MKV → MP4 → 其他受支持格式选择，后缀不区分大小写，同级按完整路径字典序选择。
- 原来保存的路径不再优先：例如曲库原指向 MP4，本次同时找到 HVIDEO 时改用 HVIDEO。
- 对照入库与删除重复共用一次选择结果。未勾选删除重复时保留所有实体文件；勾选后仅在数据库事务提交成功后删除未选中的副本。数据库写入失败不删除任何副本。
- 保留重叠扫描路径去重保护。清除旧路径优先参数、候选路径缓存及不再需要的数据库字段读取。
- 同步后台说明和 API 协议语义；HTTP 请求、响应及三端 API 字段不变。

## 修改文件

- src/scanner/duplicate_handler.rs：统一格式排序，移除旧路径优先规则，更新排序回归测试。
- src/services/song_path_matcher_service.rs：移除旧路径读取，新增实际临时文件扫描、入库、删除和数据库失败保护回归。
- static/admin/index.html：显示统一优先级及入库成功后删除的说明。
