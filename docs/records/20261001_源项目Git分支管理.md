# 2026-10-01 源项目 Git 分支管理

## 目的

将 `D:\HVIDEO\Hvideo_server` 设为 HVideo 点歌服务器唯一 Git 工作目录，关联远程仓库 `https://github.com/jevin-888/HVIDEO_SERVSER`，并在源项目内维护 `windows` 与 `linux` 两个分支。

## 处理

- 在源项目根目录初始化 Git，未再复制源码目录。
- 配置 `origin` 指向 HVIDEO_SERVSER。
- 核对源项目与远程的 Rust、前端源码一致，基于已有远程提交建立本地分支，不重写远程历史。
- 补回远程仓库的 README 与分支初始化记录。许可证保存为 `LICENSE.md`，避免 Windows 上与本机 `license/` 授权目录发生大小写路径冲突。
- 保留远程已修复的打包配置：不把本机 `data/` 与 `song_db/song.db` 打入安装包。
- 补齐 `src-tauri/icons/*.png` 的 Git 跟踪规则，防止新检出丢失打包图标。
- 本地数据库、`license/` 授权、日志、依赖目录和构建产物由 `.gitignore` 排除；本机文件继续保留。
- `windows` 保留 `yt-dlp.exe` 资源；`linux` 延续远程分支使用系统 `yt-dlp` 的差异。
- README 记录切换、拉取、推送和公共提交同步方法。

## 验证

- 检查两个本地分支均跟踪对应远程分支。
- 分别切换分支并检查工作树状态。
- 本次仅完成 Git 目录迁移与分支管理，未宣称 Linux 原生程序已经编译通过。
