## 技术细节

### 关键数据流：

1. **加载房间列表**
   ```
   loadRooms() 
   → apiService.getRooms() 
   → GET /api/v1/rooms
   → list_all_with_terminal_info()
   → LEFT JOIN terminals/songs
   → 返回 RoomWithTerminalInfo
   ```

2. **创建房间**
   ```
   openAddRoomModal()
   → 表单填写
   → apiService.createRoom(data)
   → POST /api/v1/rooms
   → RoomService::create()
   → 刷新列表
   ```

3. **更新房间**
   ```
   openEditRoomModal(id)
   → apiService.getRoom(id) 填充表单
   → 修改数据
   → apiService.updateRoom(id, data)
   → PUT /api/v1/rooms/:id
   → RoomService::update()
   → 刷新列表
   ```

### 状态码说明：
- 0: 空闲（绿色）
- 1: 使用中（红色）
- 2: 维护中（黄色）
