# 重复输出提示与批量继续（2026.09.22.2）

根因：目录计划阶段遇到任一已存在的目标文件就抛出异常，此时 UI 尚未收到文件清单，整批停止且仅底部日志显示原因。

修改：

- `scripts/encrypt_videos.py` 计划阶段只拒绝多个源文件映射至同一输出的冲突，不因磁盘已有文件阻断计划。CLI 逐个跳过已存在的输出并统计新加密/跳过数量。
- `scripts/video_encryption_ui.py` 文件/目录模式共用任务流程；列表显示“已存在，已跳过”，日志记录输出完整路径，继续处理其余文件；全部重复时标题状态明确提示“全部已存在，已跳过”。跳过数与实际加密数分别统计，重复点击时重置。
- 仅跳过普通文件；同名目录仍明确失败。跳过表示存在，不代表内容重新校验通过。底层 `encrypt()` 的原子发布及禁止覆盖保护保留，防止扫描后出现新文件时覆盖。
- 失败/取消后保留已经跳过的行状态，失败日志附当前源路径。高 DPI 自适应行高保留，状态列按“已存在，已跳过”文字宽度扩展。
- 删除旧单文件重复提示的独立分支和未使用的 EXTENSIONS 导入，保持统一实现，无服务器/PAD/播放器 API 变更。
