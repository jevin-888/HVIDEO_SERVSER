# 员工密码规则更正

- 用户确认密码支持 4–8 位数字或英文字母，可以混合，不是只能四位数字。
- 服务器 `validate_employee_password` 统一用于新增员工、编辑密码、自助修改密码，规则为长度 4–8 且 ASCII 字母数字；不更改 API 字段及数据库结构。
- 员工表单 HTML pattern/maxlength、JS 提交校验、浏览器修改密码提示、Flutter 修改密码校验同步更新；编辑留空不修改，登录仍按已有密码哈希验证。
- 五语文字同步，员工三项输入框保持同一行，较长的规则说明单独显示在首行下方。
- 测试：Rust 5 项员工测试通过，含 4/8 位纯数字、纯字母、混合密码，以及非法长度、空格、符号、全角字符拒绝；员工编辑实际 bcrypt 哈希验证 8 位混合密码通过。Flutter 35 项测试通过；浏览器员工新增/编辑/密码合法性/同行布局回归通过；静态分析通过。
- 发布仅替换现有部署目录的应用 EXE 与三个收银静态文件，保留全部数据库、配置和营业数据；收银端使用 `build-release.ps1` 唯一路径构建。缓存版本 `20260917-password-4-8`。
- 发布完成：服务器应用重启且进程响应，部署 EXE 与新编译 EXE 哈希一致；三个静态文件与源码哈希一致，收银 Release 构建成功。正式接口边界探测及 HTTP 核对/启动命令被自动审批以 `blocked by policy` 拒绝；不宣称这些现场请求通过，未改动任何真实员工密码。
