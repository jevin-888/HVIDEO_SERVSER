## 验证边界与原版行为

- 模拟 API 验证按钮至请求及返回后的 UI 流程；不代表生产数据库、真实金额支付、实体打印机出纸和 PAD/播放器整条链路已完成现场验证。
- 原版房间“测试”及本地“维护”覆盖状态仍保存在内嵌页面 localStorage，仅原版工作区内生效；服务端 status=2 的维护会在原生卡片显示。本轮未扩展服务器房态协议或迁移旧本地覆盖记录。
- 包断/活动由服务端现有计费配置匹配；现有开房 API 不含手动指定活动/包断规则 ID，本轮未添加无法对应服务端的字段。超出 OpenSessionRequest 的表单信息也未新增存储协议。
- 用户营业数据不用于自动化测试；未执行真实开房、充值、扣费、交班或修改员工密码。

## 发布

仅同步 `static/cashier/index.html`、`desktop_bridge.js`、`cashier.js`、`cashier_room_pos.js` 到现有服务器部署目录。客户端通过根目录 `build-release.ps1` 构建，唯一发布位置 `build/windows/x64/runner/Release`。发布结果另在客户端 CHANGELOG 追加。
