# 2026-09-16 视频加密工具独立 EXE

用户要求将原 Python/VBS 界面工具交付为独立 EXE。

## 交付与使用

- 双击 `D:\HVIDEO\Hvideo_server\视频加密工具.exe`。
- 单文件 Windows x64 程序，内置 Python/Tk、FFmpeg/ffprobe 和原 v1 配置。复制 EXE 即可使用，不依赖旁边的源码、JSON、Python 安装或 PATH 中的 FFmpeg。
- 文件大小 184,816,220 字节（约 176 MiB）；启动时解压内置组件，首次打开需稍等。
- 原片保护、单个/批量加密、进度、取消和输出验证沿用同一实现。FFmpeg/ffprobe 从 EXE 内置目录自动使用。
- 2026-09-22 更新：独立 EXE 只处理 `.mkv` 源视频，内置 FFmpeg/ffprobe 自动使用，界面不再提供 FFmpeg 路径选择。
- 原 VBS 入口优先启动 EXE；仅 EXE 不存在时才使用原 Python 入口。VBS 使用 UTF-16 编码，确保 Windows 脚本宿主识别中文文件名。

## 修改和构建

- `scripts/video_encryption_ui.py`：增加内置工具路径解析，优先级为用户指定目录、内置工具、系统 PATH；EXE 界面提示工具已内置。
- `scripts/build_video_encryption_exe.py`：PyInstaller onefile/windowed 构建，打包固定配置与 FFmpeg 发行版 LICENSE。所有构建中间文件在临时目录，完成后自动清理；仅构建成功后发布 EXE。
- `视频加密工具.vbs`、`docs/20260915_固定密钥视频加密.md`：更新入口及使用说明。
- 未改变加密协议或密钥，没有新增 API，也没有修改播放器、PAD、曲库或服务器进程。
- 构建命令：`python -B scripts/build_video_encryption_exe.py`。构建机需要 PyInstaller 及 FFmpeg（可用 `--ffmpeg-dir` 指定发行版 bin 目录）。本次使用 Python 3.14.6、PyInstaller 6.22.2、FFmpeg 9.0.1。
- EXE SHA256：`839d90699aef4b4dc065a2d7ea6dd4717ad440f4e157985ea4045fbd8b73d8ab`。
