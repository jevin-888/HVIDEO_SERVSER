# 2026-09-17 中控配置名称编辑修复

## 原因与修改

- 灯光、音效、空调的名称原为普通文本，编辑仅能通过悬停后显示的设置按钮进入；服务列表没有名称编辑入口。
- 四栏名称统一改为可点击按钮，显示铅笔图标及“点击修改名称”提示；弹窗带入原名称，确定保存，支持 Enter、Escape 和取消。
- 复用现有更新接口，只提交 `{ "name": "新名称" }`，保留预设 ID、控制参数、歌曲分类、排序、服务图标及启用状态。
- 防止重复打开改名弹窗；取消、空白和名称未变更时不提交；失败提示原因，成功刷新对应列表。
- 原有设置、启停、删除按钮常显；更新脚本版本参数，避免页面继续使用旧缓存。

## 接口一一对应

| 页面操作 | 现有接口 | 请求体 |
| --- | --- | --- |
| 灯光、音效、空调名称修改 | PUT /api/v1/admin/peripheral-presets/:id | `{ "name": "新名称" }` |
| 服务名称修改 | PUT /api/v1/admin/service-types/:id | `{ "name": "新名称" }` |

ID 使用 URL 路径编码。未新增后端接口或修改 PAD、播放器协议；服务端现有处理函数支持只更新名称。
