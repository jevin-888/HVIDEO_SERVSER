## 代码修改

- `src/config/mod.rs`：新增只读网络配置加载，网卡恢复不受无关密钥校验影响。启动时一次性初始化过短/空/示例 JWT 密钥并清除云端示例密钥，原子落盘成功后才继续；有效密钥和真实云端密钥保持不变。配置写锁串行化初始化和网卡保存，防止互相覆盖。
- `src/net_utils.rs`、`src/lib.rs`、`src/discover/mod.rs`、`src/discover/cashier.rs`：数据库初始化之前实际绑定并持有 HTTP 与两个固定 UDP 监听套接字，后续服务复用这些套接字，避免“检查后释放再绑定”的竞争。绑定失败显示协议、IP、端口及系统原因；部分失败时自动释放之前已申请的套接字。
- Windows 端口细节：监听套接字在绑定前启用 `SO_EXCLUSIVEADDRUSE`。Windows 允许同账户下历史非独占通配监听与后来的指定 IP 绑定并存，因此指定 IP 的固定端口还先用独占通配绑定探测已存在的冲突，再保留实际指定 IP 套接字；探测套接字不监听、不接收业务数据。瞬间跨进程端口变更仍以最终 bind 结果为准，不声称能阻止任意第三方程序在所有其他 IP 上绑定。
- `src/lib.rs`、`src-tauri/src/main.rs`：由本次后端启动发送就绪信号，替代仅探测端口可连接的就绪判断，避免其他程序占端口时误报成功。启动中的状态为未就绪。开发环境显式 SKIP_BACKEND 仍支持外部服务。保存网卡和重启共用互斥锁。
- `static/admin/bootstrap.html`：保留真实启动错误，网卡读取错误单独显示；新增刷新网卡、重试启动、查看日志。无可用网卡时允许刷新并持续检测，重新发现网卡后恢复控件；后端自动恢复后跳转登录页。
- 测试文件：配置与套接字回归直接放在对应 Rust 模块，桌面就绪回归放在桌面模块；新增 `scripts/startup-recovery-ui.test.mjs` 作为可重复运行的回归测试。
- `Cargo.toml`、根目录及桌面项目 `Cargo.lock`：将已有传递依赖 `socket2 0.6.2` 声明为直接依赖，用于绑定前配置 Windows 套接字独占选项；未升级依赖版本。
