# 2026-09-25 视频版本更新

用户要求：创建更新包新增“视频版本更新”，仅上传视频，下载后匹配点歌服务器本地源数据库入库。

实现：package_type 新增 video，沿用现有包与清单结构，不增加接口或数据库列。创建窗口、包列表、上传包选择显示视频类型。选择视频包时文件过滤限定 hvideo/mp4/mpg/mpeg/avi/mkv/mov/ts；整批预检查拦截数据库及其他文件，隐藏导入源文件入口。原有实时上传进度保留。

API：POST /api/admin/vod-updates 接受 video；POST /api/admin/vod-update-upload 增加可选查询参数 packageId，用于验证上传文件和包类型，旧调用不带参数仍兼容。上传后若不符合视频限制，清理本次文件并报错。POST /api/admin/vod-updates/files 与已有文件绑定接口均核验文件扩展名和角色，不能将数据库文件伪装为 video。视频包拒绝源文件导入；发布和修改为 published 两个入口均检查至少有一个视频且无源文件。登记文件后立即更新视频数和总大小。

客户端：现有 VodUpdateService 已支持只有视频的清单，不需要修改运行代码或替换本机 EXE。按版本顺序下载校验，从文件名提取编号，在 songs 源库匹配，然后更新歌曲路径、songFiles、local_available_songs、songSearch 和新歌批次。没有对应本地资料时包更新失败，不将不匹配视频登记为可点播歌曲。保留现有歌曲。未上传 XLSX 的包“歌曲资料数”为 0，实际更新数量按成功入库视频计算。
