# 歌曲编辑歌手搜索与评分（2026-09-28）

## 需求与验收标准

歌曲管理的数据源编辑页面必须能够按歌手名称、编号或首字母搜索并选择歌手，并提供评分编辑选项。保存后评分规则必须由服务器依据真实视频状态裁定：普通视频始终为“否”，真实加密视频始终为“是”，前端提交值不能绕过该规则。

## 修改内容

- `static/admin/index.html`：在歌曲编辑弹窗加入歌手搜索输入框和评分“是/否”选择项，并显示规则说明。
- `static/admin/admin.js`：歌手搜索改为远程检索，支持名称、编号、首字母；保留当前已选项；使用请求代次避免旧响应覆盖新结果；编辑和保存时读写 `scoreEnabled`。
- `static/admin/i18n-admin.js`：补充歌手搜索提示和评分说明的五种语言文本。
- `src/models/song_db_models.rs`：`UpdateSongRequest` 增加可选 `scoreEnabled` 字段。
- `src/services/song_db_service.rs`：保存时根据真实视频加密状态重新计算评分值，普通视频强制为 0，加密视频强制为 1。
