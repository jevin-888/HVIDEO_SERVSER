# 更新记录手动双向同步删除（2026-09-29）

## 行为

云端和点歌服务器更新记录页面均增加“同步删除”。管理员确认后删除所选已完成/失败记录，等待/运行中的记录禁止手动删除。删除只影响历史，不删除视频、曲库、更新包和 sync_tasks，已安装判断仍有效。页面显示待同步删除数量。

本地离线删除在 SQLite 事务中保存待办并删除历史。云端删除保留按机器码隔离的删除标记，客户端每 15 秒拉取，落库后回执。双方永久保留最小删除标记，防止断网旧上报、旧客户端和备份恢复后让记录复活，不再保留被删除记录的完整正文。客户服务器必须安装本次新版，旧版不会拉取删除标记。

上传记录和删除按机器码串行锁定，重复请求幂等。签名上报身份确定机器码，不能在请求中指定他人的机器码。授权过期但签名有效仍可同步记录删除，不能下载新视频。

## API 一对一

- 云端管理员 DELETE /api/admin/server-update-records/{machine}/{id}
- 客户端管理员 DELETE /api/v1/cloud/update-history/{id}
- 客户端签名 POST /api/server-update-records/sync-deletions：deleteIds / ackIds，每批最多 100 条，返回 acceptedIds / ackIds / deletedIds
- 原 report 响应增加 deleted，旧版兼容，新版收到后删除本地对应记录并等待回执
- 列表新增 pendingDeletes，云端计数按服务器筛选，本地计数包含未同步的所有云端地址
