# 收银服务器发现协议 v1

收银端启动/重连时主动请求，服务器单播回复，不周期广播服务器身份，不扫描子网。接收端口固定为 **18081/UDP**，与播放器 18080/v2 完全独立。

## 请求

客户端以每张有效 IPv4 网卡的临时 UDP 端口，向实际掩码计算的子网广播地址发送；为兼容同机部署，也向本机该网卡地址单播。每轮立即、500 毫秒、1000 毫秒各发一次，总发现期限 5 秒，成功即停止。

```json
{"type":"hvideo_cashier","protocol":"discover","protocol_version":"1.0","requestId":"0123456789abcdef0123456789abcdef"}
```

`requestId` 是本轮生成的 16 个安全随机字节的 32 字符十六进制表示。服务器拒绝缺失、长度或字符不符、错误协议/版本、超过 1024 字节的请求。每次重新连接更换 ID，同轮重试复用 ID。

## 回复

服务器只回复请求来源 IP 和 UDP 临时端口，回复 socket 绑定配置选定的 `server.host`，使用系统分配的临时源端口。18081 接收 socket 绑定通配地址以接收 Windows 广播；HTTP/业务服务仍严格绑定选定网卡。

```json
{"type":"hvideo_server","protocol":"cashier_discover","protocol_version":"1.0","device_role":"server","app_id":"com.hvideo.server","requestId":"0123456789abcdef0123456789abcdef","serverPort":9898}
```

`serverPort` 直接取当前实际 `config.server.port`，范围 1–65535。客户端必须严格匹配上面所有标识及本轮 ID，使用 **UDP 回包来源 IPv4** 与 `serverPort` 组成 `http://来源IP:端口/api/v1`，不信任 JSON 自报地址。

随后 GET `/api/v1/license/status`，严格验证现有 `code/data` 和 `machineCode`、`licensePath`、`valid`、`status`、`message` 字段；不发送账号密码/Token、不跟随重定向。HTTP 可达且协议符合才允许登录。缺失/过期授权可被识别，登录时仍由服务器执行业务授权检查。UDP 随机 ID 仅关联本轮请求，并非加密服务器身份认证。

## 生命周期与兼容性

- 优先校验已经保存的 HTTP/HTTPS 地址，成功可不发广播。无响应或 HTTP 验证失败显示未连接，可按“重新连接”。空配置不回退到 127.0.0.1。
- 客户端取消、退出或找到服务器后关闭 UDP socket/定时器及 HTTP 探测，拒绝迟到回包；不会在后台持续广播。
- 发现无需授权，不读写数据库、不注册播放器/房间。播放器 v2 与 online_vod 服务提示保持原协议。
- 必须同时更新服务器和客户端。旧服务器没有 18081 响应能力；没有可用的已保存地址时，新客户端不会退回 IP 扫描。
- 广播一般仅在同一广播域有效。能 ping 通的跨 VLAN/路由网络未必能广播到达；本协议不承诺跨广播域自动发现。防火墙须允许 18081/UDP 及实际 HTTP TCP 端口。

## 验证入口

服务器：`cargo test --lib discover:: --locked`。收银项目：`flutter test --no-pub`。
