# 手机点歌双语与歌星筛选

日期：2026-09-25

## 修改

- 删除点歌页 HOT／热门、A–Z、0–9 的整行快捷标签及对应状态、事件代码。顶部搜索仍可按首字母或歌名搜索；歌名按钮返回歌曲列表，语种及分类的选项保留。
- 歌名、语种、分类、印尼歌曲四按钮采用中文主标题＋当前语言副标题；英语、印尼语、越南语使用现有翻译资源，中文模式仅显示中文，不重复。关闭点歌页后切换语言，再打开时也会更新。
- 增加手机按钮双语样式，小屏可换行且四按钮保持等宽。
- 更多歌星改为读取 `/api/v1/system/dicts` 的标准字段 `dictGroup`、`dictCode`、`dictName`、`visible`、`sortOrder`。优先使用可见项；某组全部隐藏时，以同一响应中该组的实际名称和编码恢复选项，避免只剩“全部”。未修改服务器字典数据。
- 修正手机筛选参数 `sex`／`region` 与共享服务不匹配的问题，统一为 `sexCode`／`regionCode`。字母搜索缓存加入性别和地区，中文搜索也传入当前筛选，避免跨条件复用旧结果。“全部”默认高亮。
- 清理旧硬编码歌星筛选数组，避免服务器编码变化后错误对应地区。

## PAD 对照

实际点歌 PAD 项目为 `D:\HVIDEO\Fultter_pad`。`D:\CHUANGWEI\Fultter_pad` 当前是素材／控制／场景控制端，不包含点歌字典逻辑。

参考点歌 PAD 的：

- `lib/data/repositories/system_dict_repository.dart`：从 `/system/dicts` 获取字典。
- `lib/data/models/dict_entry_model.dart`：使用后台标准字段并按可见性、排序处理。
- `lib/presentation/pages/search_page.dart`：整组不可见时提供兜底筛选。
- `lib/data/repositories/song_catalog_repository.dart`：歌星列表请求传递 `sexCode`、`regionCode`。

现场 sex／region 项全部为 visible=0，因此手机之前全部过滤掉；PAD 有兜底但旧地区编码不完全适用于当前服务器。手机本次使用服务器原有编码兜底，例如日本为 7、欧美为 16，未照搬 PAD 的旧编码，也未更改 PAD 源码。
