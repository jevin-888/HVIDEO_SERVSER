# 加密工具界面与 MKV 筛选（2026-09-22）

## 修改

- `scripts/encrypt_videos.py`：可处理输入后缀收窄为 `.mkv`。目录扫描忽略 `.mp4`、`.m4v` 等其他格式；单文件模式对手工输入的非 MKV 路径直接提示不支持。
- `scripts/video_encryption_ui.py`：文件选择器只显示 MKV；任务列表不会再列出其他格式，也不会把它们显示成“未处理”。
- 移除 FFmpeg 目录输入框和说明。程序继续从 EXE 内置的 `tools` 目录查找 FFmpeg/ffprobe，源码运行时使用系统 PATH 作为回退。
- 移除输出文件夹下面的说明文字，保留输出目录本身和任务状态信息。
- 日志文本增加上下行距，任务列表固定 24 像素行高，避免上下行挤在一起。
- 校验阶段改为读取全部加密视频包并容错解码音轨，视频不再重复做整片软件解码；仍会拦截致命 FFmpeg/容器错误，播放器可容忍的 AAC 异常帧不会阻止加密。
