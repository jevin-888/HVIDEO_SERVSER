# 2026-09-16 终端管理批量删除

## 功能与接口

- 终端序列号前增加勾选框，表头可全选/取消全选当前搜索结果，显示已选数量和批量删除按钮。
- 搜索时清除被隐藏的选中项，状态刷新保留仍然可见的选中项；空列表和未选择时禁用删除。
- 单台和批量删除共用一个流程：读取关联房间、确认终端及关联房间/点歌队列范围、逐台删除、刷新终端和房间列表。
- 删除或确认期间锁定选择、搜索和删除按钮，防止重复提交；取消确认不发出 DELETE。
- 成功项取消勾选，失败项保留并显示错误原因，支持重试。终端再次注册时可能重新出现在列表中。
- 大量终端的确认清单截断展示，保留准确总数；确认文本支持换行、滚动与长名称折行，按钮保持可见。
- 复用 GET /api/v1/terminals/:id/rooms 和 DELETE /api/v1/terminals/:id。ID 统一按 URL 路径编码；没有新增后端 API 或字段，没有修改 PAD/播放器协议。
