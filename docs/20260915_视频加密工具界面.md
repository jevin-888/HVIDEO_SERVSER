# 2026-09-15 视频加密工具界面修改记录

用户要求：现有视频加密工具需要 UI 操作。

## 交付

- `D:\HVIDEO\Hvideo_server\视频加密工具.vbs`：双击启动中文工具，使用本机 Python，不显示命令行窗口。
- `scripts/video_encryption_ui.py`：Tkinter 桌面界面，支持单视频/目录递归、选择输出文件夹、任务列表、阶段进度、完成数量、错误记录、停止和打开输出目录。任务在后台线程执行，UI 在主线程更新；处理中禁用输入，防止重复启动。
- 2026-09-22 更新：界面只处理 `.mkv`；FFmpeg/ffprobe 从程序内置位置自动查找，不再显示路径选择控件；输出文件夹下的说明文字已移除。
- `scripts/encrypt_videos.py`：复用同一加密路径，新增可选 JobControl、真实 FFmpeg 媒体时间进度、子进程取消与回收、发布前取消检查、可取消的目录扫描。命令行调用保持兼容，固定密钥和格式不变。Windows 子进程不弹出控制台。
- 修复 Windows 的 `communicate(timeout)` 无法提供增量输出的问题：独立线程持续读取进度，后台任务定期更新 UI；错误输出使用自动清理的临时日志，避免子进程管道堵塞。
- `tests/test_video_encryption_ui.py`：保留正式回归代码，临时生成媒体和输出自动清理。
- `docs/20260915_固定密钥视频加密.md`：加入图形界面使用说明。

## 验证

- 原有 10 项加密回归通过，覆盖本地/网络解码、密钥、目录处理与原片保护。
- 新增 7 项回归通过：实际 Tk 开始按钮单文件加密、批量处理/同名文件提示、空输入校验、真实 FFmpeg 运行中停止且子进程结束、校验阶段停止不发布半成品、关闭窗口等待清理、真实媒体时间进度。
