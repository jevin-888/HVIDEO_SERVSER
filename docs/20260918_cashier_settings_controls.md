# 收银基础设置翻译及选择控件

- 后续根据用户反馈，单选控件改为贴着原字段的下拉列表（空间不足向上展开），不再使用居中弹窗和遮罩；点击选项立即回填，支持点击外部关闭及键盘方向键/Escape。浏览器回归加入定位、无模态遮罩、外部关闭断言并通过。当前缓存版本 `20260918-anchored-select`，仅调整呈现，不改变 API。
- 新增 `static/cashier/settings_translations.js`，补全基础规则、房型价格、买断时段、活动、套餐、赠品的印尼文、越南文、泰文、英文及弹层文案；后台配置的房型/商品等名称不改写。
- 新增 `settings_controls.js`，select/time 用页面 DOM 弹层选择，避开内嵌 WebView 原生弹窗显示问题；保留原控件 value、input/change 事件与禁用状态。鼠标/触控和 Enter/Space/向下键打开，Escape 取消；深色背景和高对比文字。
- 现有日期控件补充动态绑定，日历标题和星期本地化；星期选择的“每天”与具体星期互斥。翻译记忆原始键避免同义译文在语言切回时变成错误中文。
- 房型、商品请求失败显示错误，不吞错为空数组。API 路径、请求字段及数据结构不变。
- 三组浏览器回归通过；新增真实控件点击测试及保存后刷新回读，验证房型 1、星期 [1,5]、开始时间 09:30；四种外语逐页扫描基础设置六页签和星期/日历弹层文字。键盘取消和星期取消不改值。
- 本轮测试采用隔离内存 API，不修改现场计费配置。Edge 浏览器测试不等同于全部现场 WebView 设备验证。
- 发布包含 index.html、cashier.js、settings_translations.js、settings_controls.js；版本 `20260918-settings-controls`。收银端更新页面缓存标识并通过唯一 build-release.ps1 构建。
