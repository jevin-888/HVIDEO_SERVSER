# 手机歌名搜索修复

日期：2026-09-25

## 修改

- 搜索框中文提示改为“请输入歌名搜索”，保留当前语言第二行。英文：`Enter a song title to search`；印尼文：`Masukkan judul lagu untuk mencari`；越南文：`Nhập tên bài hát để tìm kiếm`。
- 搜索明确发送 `keyword` 和 `searchMode=fullName`，不再携带搜索时已隐藏的语种、分类、歌星筛选。
- 删除原来无实际等待作用的搜索处理标记，使用 300 毫秒防抖；中文输入法组词期间不查询，提交后按最终歌名查询。
- 新的首页/搜索查询可以替换未完成的列表查询，旧响应和旧错误不再覆盖最新结果，解决加载中输入被忽略的问题。
- 清空搜索取消尚未执行的查询，并恢复歌曲列表；搜索结果支持继续分页加载。
- 缓存保留，接口路径、字段和服务器查询规则保持一致。

## 验证

- 修复后实际手机网页连续搜索“后来”“成都”“青花”，结果分别显示对应歌曲和歌星。
